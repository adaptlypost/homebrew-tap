# adaptlypost Homebrew tap

```bash
brew trust adaptlypost/tap
brew install adaptlypost/tap/adaptlypost
```

Installs the standalone `adaptlypost` binary, with `apost` as a shorter alias. No Node
required. Source and issues live at https://github.com/adaptlypost/adaptlypost-cli.

`npm install -g @adaptlypost/cli` is the other way in, if you would rather have it as a
Node package.
